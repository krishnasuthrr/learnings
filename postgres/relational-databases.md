- **Terminal** \(The Window\): provides a CLI to type commands, and see the output on display
- **Command Line** \(The Text prompt\): The actual command/text you type as a series of characters using your keyboard in the command window \(terminal\)
- **Shell** \(Translator and Brain\): Translates, Interprets the commands typed into the terminal and checks for syntax, executes using system kernel
    - breaks the command down, tokenizes it, and evaluates syntax, instructions
    - Kernel does the under the hood execution

> These are used to write and execute System/OS level commands.

### RELATIONAL DATABASES & SQL
---

Data is strctured and stored in a **tablular** form \(Tables consisting of rows and columns\)
    - **Rows**: Individual entities of the entire record
    - **Columns**: Properties/Attributes of each entity

Data tables can be connected/related to each other using joins

**Schema**\(The Blueprint\): provides a shape, structure or architecture to the data in a database using tables, columns, datatypes, joins/relationships, constraints etc.
In **NoSQL** databases, schemas are more felxible than Relational DBs, they aren't strictly restricted to a tabular form, they can have different shapes and structures such as JSON, key-value, graph etc.

### Primary Properties of SQL
---

- The Language of Relational Databases.
- Queries \(Commands or instructions for data management\) follow a specific syntax
- Operations on Data:
    - CRUD
    - Sorting, Filtering, Aggregating
